### Added (tooling)
- **Update checks for every vendored SDK and the upstream protocol documents** (`scripts/dependency_updates.py`, `scripts/dependency_sdk_versions.json`): the ten SDKs now each have an automatic source (ZWO's SDK JSON endpoint; the QHY changelog; the SVBONY, ToupTek and Player One download pages; libgpiod), so none is left as a manual check, and a new `documents` list watches 20 upstream references against a reviewed baseline: the SkyWatcher, SynScan and iOptron protocol PDFs, the Bisque and Losmandy reference pages, Wanderer's dated protocol PDFs, the Gemini and Oasis ASCOM installers their protocols were recovered from, the seven INDI driver files the iOptron, Wanderer, Celestron and ZWO AM drivers were derived from, and the ConformU beta tarball. A changed document opens one issue (`dependencies`, `documentation`, `P4`) that closes when a pull request sets its baseline to the new value. `--pin` keeps the `documents` list and `--check` fails when a document's local copy is missing.
